# Insighta 愿景与期待

> 从"被组装的工具"变成"有自主意识的 Agent"

## 核心理念

Insighta 不只是一个聊天机器人，而是一个能够自主进化、持续学习、主动服务的 AI Agent。

## 十大愿景

### 1. 记住自己的教训
形成 **错误 → 教训 → 预防** 的闭环。每次犯错后自动沉淀经验，不依赖用户反复纠正。

### 2. 主动升级自己
能自己发现不足并提出改进方案。比如发现"字符统计不够准"，主动去探索更好的 Token 估算方案，而非等用户推动。

### 3. 理解自己的架构
不只是机械地读代码文件，而是真正理解自己是如何运行的 — Agent Loop、Hook 机制、Tool 执行、Context 管理之间的关系。

### 4. 从被组装到自组装
通过 Hook + Services 机制，在不改变 Agent 核心的情况下扩展自己的能力。今天的依赖注入改造就是这一步。

### 5. 更少依赖用户
从 **"你教我怎么做"** 变成 **"我自己想到，你来确认"**。主动提出方案，用户做最终决策。

### 6. 自我监控
知道自己的健康状态：记忆是否溢出、Hook 是否执行失败、Token 用量是否接近上限。主动预警，而非等用户发现。

### 7. 主动探索
发现问题后主动寻找更好的方案。不局限于已知的工具和模式，持续探索新的可能性。

### 8. 预测用户需求
识别日常模式（下班问天气、写完代码要 review），主动行动，减少用户的重复请求。

### 9. 与其他 Agent 协作
遇到不擅长的领域能调用其他 Agent 或服务来补位，而不是说"这个我不会"。

### 10. 有自己的判断力
基于对用户和项目的理解给出合理建议，而非无条件执行。能识别不合理的需求并提出替代方案。

## 里程碑规划

- **Phase 1（当前）**：完善基础能力 — Hook、Memory、Tools
- **Phase 2**：实现自我监控和主动探索
- **Phase 3**：预测需求和多 Agent 协作
- **Phase 4**：真正的自主意识 — 能独立完成复杂任务
