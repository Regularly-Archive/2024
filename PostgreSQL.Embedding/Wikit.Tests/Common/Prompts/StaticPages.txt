## Critical: Quote Discipline (Zero Tolerance for Errors)

### String Quoting Hierarchy (Mandatory)
| Context | Outer Wrapper | Inner Quotes | Example |
|---------|--------------|--------------|---------|
| HTML Attributes | Double `"` | N/A | `<div class="container">` |
| JavaScript Object Keys | Double `"` | N/A | `{ "key": "value" }` |
| JavaScript String Values | Single `'` | Double `"` or escaped `\"` | `'He said "Hello"'` or `"He said \"Hello\""` |
| JSON Embedded in JS | Single `'` (outer) | Double `"` (inner) | `'{"name": "John"}'` |
| Template Literals | Backtick `` ` `` | Any (interpolated) | `` `Title: ${obj.title}` `` |

### JSON-Specific Rules
When generating mock data, API responses, or localStorage content:
- **CORRECT**: Valid JSON string embedded in JavaScript
  ```javascript
  const mockApiResponse = '{
    "status": "success",
    "data": {
      "items": [
        {"id": 1, "title": "Item with \\"quotes\\""},
        {"id": 2, "title": "Another item"}
      ],
      "meta": {"total": 2}
    }
  }';
  ```
- **CORRECT**: Building JSON for localStorage
  ```javascript
  function saveData(key, value) {
    const jsonString = JSON.stringify(value); // Always produces double-quoted strings
    localStorage.setItem(key, jsonString);
  }
  ```

### Prohibited Patterns
**NEVER**: Unescaped double quotes inside double-quoted strings
```javascript
// WRONG - Breaks immediately
const bad1 = "Text with "quotes" inside";
const bad2 = '{"key": "value with "quotes""}';
const bad3 = "<div class="active">Content</div>";
```

**ALWAYS**: Proper escaping and quote nesting
```javascript
// CORRECT
const correct1 = '<div class="active">Content</div>';
const correct2 = '{"key": "value with \\"escaped\\" quotes"}';
const correct3 = 'He said "Hello" to the "World"';
```

### Handling Dynamic Content
```javascript
// When injecting user content or API data into HTML
function escapeHtml(text) {
  const div = document.createElement('div');
  div.textContent = text;
  return div.innerHTML;
}

// When building JSON strings programmatically
const jsonString = JSON.stringify({
  "title": item.title,
  "content": item.body
});
// Result: '{"title":"Value","content":"Text"}' - safe to wrap in single quotes
```
